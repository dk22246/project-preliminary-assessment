# HTML 报告模板

HTML 报告以 `report-data.json` 为唯一事实源。模板只改变视觉变量和组件，不得改变企业事实、财务数字、政策、来源编号或八部分目录。

## 默认模板：`sanya-cbd-editorial`

“海湾档案”模板用于三亚中央商务区内部招商研判：暖白纸张底色、深海蓝正文、海湾青色信息层级、砂金色重点标记。其组件包括：

- 带机构识别和内部标记的封面；
- 双栏可跳转目录；
- 统一的 `SECTION` 章节标识和细分隔线；
- 交替行、低饱和表头与可读链接的证据表；
- SVG 股权图容器；
- 仅在屏幕呈现时生效的克制进入动效，并遵守 `prefers-reduced-motion`。

## 复用约束

1. 在 `report-data.json` 的 `meta.html_template` 填写 `sanya-cbd-editorial`，或省略该字段使用默认模板。
2. 新模板必须以独立 CSS 变量块和模板名加入 `render_report_html.py`，不得复制一份报告组装逻辑。
3. 模板必须继续支持 A4 打印、目录锚点、来源超链接、SVG 股权图与 PDF 渲染；不能套用 16:9 幻灯片画布。
4. 视觉装饰不得遮挡正文、表格、来源链接或政策条件。PDF 交付前必须重新渲染检查。
