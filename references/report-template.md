# 招商项目整体落地研判报告

报告供内部招商决策和谈判准备使用，默认以 Word（.docx）交付。现状事实、政策条件和招商推演假设必须分开写。最终报告严格使用以下八部分目录，不得自行增加、删除、合并或调整章节顺序。

## 一、项目整体判断

控制在一页以内，只呈现结论，不展开详细论证。直接说明企业是谁、综合实力和行业位置、最适合在三亚落地的业务、最重要的政策匹配、主要风险及是否建议继续推进招商。

| 研判事项 | 初步结论 |
| --- | --- |
| 企业综合实力 | 强、较强、一般或较弱 |
| 行业地位 | 企业实际行业位置 |
| 建议落地业务 | 最核心的 2—4 项 |
| 主要政策匹配 | 价值最高的正式政策 |
| 主要风险 | 简要说明 |
| 招商建议 | 重点推进、保持跟进或暂缓 |

## 二、企业基本情况

### （一）企业主体及关联关系

说明企业正式名称、集团/上市公司/品牌/子品牌/子公司关系、成立时间、注册地、控股股东和本报告采用的具体分析主体。不得混用集团、上市公司、品牌和子公司的业务及财务数据。

### （二）主要业务及产品

简洁说明企业主营业务、主要产品或服务、核心收入来源及主要客户或市场。不写无关发展历史。

### （三）行业地位及竞争位置

说明行业地位、市场份额、行业排名、主要竞争对手和竞争位置。只有取得权威数据时才写具体市场份额；未找到可靠数据时明确说明，不得推算或编造。本报告不再单独分析行业市场规模。

### （四）上下游及国内外业务

只保留代表性上游企业 1—2 家、代表性下游企业 1—2 家、国内业务现状及海外业务/海外市场/境外子公司或跨境业务现状。上下游企业必须有公开事实支持，不得根据普通合作新闻随意认定为核心客户或供应商。
