# 岗位与交接

## 专业岗位

| 岗位 | 核心工作 | 必须交付 |
| --- | --- | --- |
| 信息采集专员 | 收集企业原始资料、官方网页和公开风险信息，确认主体边界。 | 企业事实卡：每项关键事实标原始链接、文件页码、表格或段落。 |
| 企业业务研判专员 | 研判集团、产品、供应链、渠道、电商、海外业务和战略。 | 整体迁入业务清单：业务、主体、人员、收入、利润、结算和管理安排。 |
| 财务税务与政府资源专员 | 提取三年财税、现金流、补助、专项资金及附带义务。 | 财税与政府资源卡：数据口径、来源、可迁入税源基础和政策诉求。 |
| 海南政策与产业匹配专员 | 由检索线索联网核验海南/三亚正式政策，研判产业结合点。 | 政策卡：官方原文、地域、状态、适用对象、企业承接业务和落地动作。 |
| 落地方案与谈判专员 | 把业务、财税、政策和风险转为经济贡献与谈判指标。 | 贡献测算和谈判指标清单。 |
| 项目负责人 | 统一事实、数字、政策和结论口径。 | 一份统一报告及项目结论。 |

## 共享卡片与门禁

1. 企业事实卡；
2. 财税与政府资源卡；
3. 政策卡；
4. 风险与重要信息卡。

所有卡片必须带来源。项目负责人不得以未写入卡片的事实、政策或数字形成结论；数字口径、主体口径、地域和政策状态冲突时，退回相应岗位核验。
