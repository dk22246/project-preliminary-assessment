# 企业研究快路径索引

仅在主体确认后读取与 `enterprise-findings.json.research.enterprise_profile.research_route` 相符的一段；不得同时加载两套执行细则。

## listed_disclosure

1. 最新年度报告是集中主资料，同一文件只下载和解析一次，同时提取主体、业务、产品、近三年财务、股权、政府补助和重大风险。
2. 以前年度报告仅在最新年报缺少具体历史字段时定向补缺，不完整重读。
3. 企业官网只补当前产品、最近一年重大变化、近期战略和海外布局缺口。
4. 政府监管只补年报后发生或年报未解决的重要处罚、诉讼和监管事项。
5. 以上动作合并为一轮集中研究；可并行URL一次批采集。完成动作和候选处置后停止；已由法定披露确认的事实不得再用媒体或商业平台重复证明。

## nonlisted_public_evidence

1. 企业官网、官方公众号或正式材料中的产品、服务、解决方案和项目；
2. 政府项目、备案、许可、采购和招投标记录；
3. 客户或合作方正式公告；
4. 公开登记、股权和主体关系；
5. 行政处罚与经营异常、税务违法、重大诉讼执行、失信信用四类官方风险；
6. 固定来源阶梯为第一轮；之后仅允许一次会改变招商结论的定向缺口补查，最多两轮。每轮中的独立URL一次批采集。

完成固定路径后停止。财务、员工、行业500强或股权仍无可靠公开数据时明确写需企业补充，不转向无关网站泛搜，不估算。

主体、财务、目录匹配和三亚落地路径完成后，由 `prepare-enterprise` 独立推进至 `landing_businesses_complete`；政策输入不参与该门禁。目录阶段固定读取现有 Excel 与同源 JSON 唯一内置库；匹配阶段引用 `catalog_entry_id` 与0基索引 `detail_index`，单个 detail 可默认 `0`，多个 detail 必须明确选择，由程序派生原文条号，后续只引用派生结果，AI判断经营行为和技术条件，保留版本与官方出处。本地库不代替实时政策有效性核验；发现官方变更时提示更新，不自动无证改库。
