# 网页证据来源登记

网页证据采集只服务于公开事实取证，不替代政策正式性和地域校验。

| 来源类别 | 默认允许范围 | 用途 |
| --- | --- | --- |
| 政府及监管 | `https://*.gov.cn` | 政策原文、实施口径、监管和处罚公开信息。 |
| 法定披露 | 巨潮资讯、上交所、深交所、港交所披露易、SEC、NASDAQ、NYSE | 年报、公告、招股文件和法定披露。 |
| 企业正式材料 | 仅通过 `--allow-domain` 显式登记并确认其为企业官网后允许 | 主体、产品、业务、投资者关系材料。 |

禁止将搜索结果页、自媒体、商业信息聚合站、论坛、营销站、登录页或付费/受限页面交给采集器。传入企业官网域名即表示已完成官网主体核验；这不会把企业自身宣传转化为财务、风险或政策结论的唯一依据。

采集器只抓公开 HTML 正文，并发现同页 PDF/DOCX 链接。附件仍须按现有文件提取流程阅读和定位。每次使用后运行 `scripts/validate_evidence.py evidence.json`；失败记录必须保留，不得删除或补写为成功。
