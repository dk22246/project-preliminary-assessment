# 证据台账

| 材料类型 | 必记定位 | 使用规则 |
| --- | --- | --- |
| PDF | 文件名、页码、表格名称或段落 | 财务、补助、处罚、政策结论均要可定位。 |
| Word | 文件名、标题层级、表格位置 | 不以转述替代原文定位。 |
| Google 文档 | 标题、链接、段落/表格位置 | 记录可访问链接及引用位置。 |
| 网页 | 标题、发文机关、发布日期、直接链接 | 政策优先官方原始文件。 |

用户提供文件优先于网页二次摘要，但不替代现行政策的官方检索。上市公司财务优先年报、交易所公告和审计报告；每个政府补助、税费、处罚、诉讼和政策结论均须进入台账。来源不足的结论标为“待核”，不得当作事实。

## 网页证据采集

在确定企业主体、拟落地业务和需核验主题后，先由 Agent 找到候选的官方或法定披露 URL，再使用 `scripts/collect_web_evidence.py` 采集公开 HTML。例如：

```powershell
& $py scripts/collect_web_evidence.py "企业名称" "海南跨境贸易政策" --url "https://hainan.chinatax.gov.cn/..." --out-dir evidence/enterprise-policy
& $py scripts/validate_evidence.py evidence/enterprise-policy/evidence.json
```

企业官网仅在已核验主体后，作为显式 `--allow-domain` 传入。采集器不登录、不保存 Cookie、不绕过验证码；仅收集公开网页正文并发现页面内 PDF/DOCX 链接。失败记录必须保留。

采集到的新闻、规划、招商宣传和企业宣传仅是线索，不能替代财务、风险或政策原文。将已校验 `evidence.json` 通过报告流水线的 `--evidence` 参数传入；再按本文件和 `references/policy-scope.md` 的证据层级写入 `report-data.json`。网页取证不能绕过政策正式性、地域、现行状态和企业承接路径校验。

## 企业公开信息检索规则

### 企业研究范围

只研究以下内容：

1. 企业主体关系：集团、上市公司、品牌、子品牌和子公司之间的关系；
2. 成立时间、注册地、控股股东；
3. 主要业务和主要产品；
4. 行业地位、市场份额和竞争位置；
5. 代表性上下游：分别选择 1—2 家有公开事实支持的重要企业；
6. 国内业务和海外业务现状；
7. 最近三个完整年度的营业收入、利润、公开税费线索及政府补助；
8. 重大风险、行政处罚、税务违法、重大诉讼、执行失信及其他可能影响招商判断的事项。

不单独扩展行业市场总规模、软实力、员工规模、专利数量、门店数量等非必要内容。股权架构、业务板块和可迁移职能属于必要内容，应以官方披露或企业正式材料核验。

### 上市公司来源

先判断企业在哪个交易所上市，再检索对应交易所或法定信息披露平台。

核心依据为：

1. 年度报告；
2. 招股说明书；
3. 交易所正式公告；
4. 企业投资者关系栏目；
5. 政府及监管部门信息；
6. 必要的主流媒体补充。

营业收入、利润、业务构成、子公司关系、国内外收入和重大风险原则上以法定披露文件为准。

### 非上市公司来源

按以下顺序检索：

1. 企业官网及正式官方材料；
2. 政府部门、监管机构和地方政府官方信息；
3. 与企业所在地或项目直接相关的地方官方媒体；
4. 全国性主流媒体或权威财经媒体。

官方媒体和主流媒体只选择最直接、最权威的 1—2 个来源，不得为增加篇幅重复堆砌报道。

不得采用：

- 小道消息；
- 自媒体和营销号；
- 无原始出处的转载；
- 明显的商业软文；
- 论坛、短视频口播和匿名爆料；
- 低质量商业信息汇总网站。

商业企业信息平台最多用于发现主体或风险线索，不得直接作为核心财务、业务及风险结论的唯一依据。

非上市公司收入、利润或纳税数据无法可靠取得时，直接写明“本轮公开检索未发现可靠数据，需企业补充”，不得根据注册资本、融资金额、产值或估值进行推算。
