# 证据台账

| 材料类型 | 必记定位 | 使用规则 |
| --- | --- | --- |
| PDF | 文件名、页码、表格名称或段落 | 财务、补助、处罚、政策结论均要可定位。 |
| Word | 文件名、标题层级、表格位置 | 不以转述替代原文定位。 |
| Google 文档 | 标题、链接、段落/表格位置 | 记录可访问链接及引用位置。 |
| 网页 | 标题、发文机关、发布日期、直接链接 | 政策优先官方原始文件。 |

用户提供文件优先于网页二次摘要，但不替代现行政策的官方检索。上市公司财务优先年报、交易所公告和审计报告；每个政府补助、税费、处罚、诉讼和政策结论均须进入台账。来源不足的结论标为“待核”，不得当作事实。

## 网页证据采集

### 正式政策实时取证

每轮正式报告的前台政策均须在同一工作区生成 `policy-evidence.json`。每条记录绑定 `P` 类正式来源、本轮抓取时间、最终官方 URL、网页或附件文件、SHA256、发文机关、文号、现行效力依据及定位、当前申报/办理状态及依据。HTTP 成功不是现行有效证明。

正式模式不得使用示例、fixture 或历史摘要；政策正文、实施细则和申报通知可分别取证后共同支撑同一政策卡。抓取文件和台账保持在项目工作区，不写入正式报告。正式取证由 `ppa.py advance` 统一校验，失败时禁止生成交付物。

在确定企业主体、拟落地业务和需核验主题后，先由 Agent 找到候选的官方或法定披露 URL，再通过唯一公开入口采集并自动校验公开 HTML：

```powershell
& $py -X utf8 scripts/ppa.py collect-web "企业名称" "海南跨境贸易政策" --url "https://hainan.chinatax.gov.cn/..." --out-dir evidence/enterprise-policy
```

企业官网仅在已核验主体后，作为显式 `--allow-domain` 传入。采集器不登录、不保存 Cookie、不绕过验证码；仅收集公开网页正文并发现页面内 PDF/DOCX 链接。失败记录必须保留。

采集到的新闻、规划、招商宣传和企业宣传仅是线索，不能替代财务、风险或政策原文。将已校验 `evidence.json` 通过报告流水线的 `--evidence` 参数传入；再按本文件和 `references/policy-scope.md` 的证据层级写入 `report-data.json`。网页取证不能绕过政策正式性、地域、现行状态和企业承接路径校验。

## 企业公开信息检索规则

### 披露类型路由

主体确认后，先判断本报告的 `analysis_entity` 本身是否为上市主体，并将结果写入 `research-ledger.json.enterprise_profile`。只允许两条路由：

| 分析主体状态 | research_route | 作用 |
| --- | --- | --- |
| 本身已在交易所上市 | `listed_disclosure` | 以最新年度报告为主资料，集中取得近三年业务、财务、股权和风险证据；只对未解决缺口定向补查。 |
| 本身未上市 | `nonlisted_public_evidence` | 跳过无依据的交易所检索，以企业官方、政府监管、工商股权、项目经营和风险记录为主。 |

集团、品牌、母子公司或项目公司仍按 `references/entity-resolution.md` 确定主体、财务和风险口径，不增加新的主体分类。非上市分析主体即使属于上市集团，仍走非上市路由；母公司年报只能作为关系或背景补充，不得把集团合并数据改写为该主体自身数据。

两条路由只影响企业研究阶段。鼓励类产业目录、三亚落地业务和海南政策仍在企业事实形成后按同一逻辑处理。

路由确认后先由 `ppa.py research-plan` 生成本轮行动清单，并按 `references/research-route-index.md` 对应段执行。行动按规范化URL去重；同一PDF只下载和解析一次。研究结果写入 `enterprise-findings.json`，正式研究台账由编译器生成，不得另写企业专用台账脚本。

### 企业研究范围

只研究以下内容：

1. 企业主体关系：集团、上市公司、品牌、子品牌和子公司之间的关系；
2. 成立时间、注册地、控股股东；
3. 主要业务和主要产品；
4. 行业地位：上市主体可核验具体品类排名、市场份额和竞争位置；非上市主体只核验三类固定500强与一项直接相关的行业500强；
5. 代表性上下游：分别选择 1—2 家有公开事实支持的重要企业；
6. 国内业务和海外业务现状；
7. 最近三个完整年度的营业收入、利润、公开税费线索及政府补助；
8. 重大风险、行政处罚、税务违法、重大诉讼、执行失信及其他可能影响招商判断的事项。

不单独扩展行业市场总规模、软实力、专利数量、门店数量等非必要内容。员工规模只作企业概况字段检索一次：有可靠数据则填写，没有则明确写“本轮公开检索未发现可靠数据，需企业补充”，不得继续扩展搜索或估算。股权架构、业务板块和可迁移职能属于必要内容，应以官方披露或企业正式材料核验。

### 上市公司来源

先判断企业在哪个交易所上市，再检索对应交易所或法定信息披露平台。

核心依据为：

1. 年度报告；
2. 招股说明书；
3. 交易所正式公告；
4. 企业投资者关系栏目；
5. 政府及监管部门信息；
6. 必要的主流媒体补充。

营业收入、利润、业务构成、子公司关系、国内外收入和重大风险原则上以法定披露文件为准。

上市路由必查并在 `research_stop_gate.source_channels` 处置：`exchange_disclosure`、`company_official`、`government_regulatory`。

具体执行顺序固定为：

1. 以最新年度报告作为集中研究主资料，一次提取主体、业务、主要产品、近三年财务、国内外收入、政府补助、股权与重大风险；
2. 最新年报缺少历史变化或逐年明细时，只打开以前年度报告对应章节定向补缺，不完整重读三份年报；
3. 企业官网只检查当前产品与业务、最近一年重大变化、近期战略和海外布局缺口；
4. 政府及监管来源只检查年报后发生或法定披露未解决的重要处罚、诉讼和监管事项；
5. 法定披露已经明确的事实不再使用媒体或商业平台重复证明，主流媒体仅在重大收购、行业位置或风险缺口无法由正式来源确认时补充一次。

完成必查主题、来源处置和全部业务候选处置后，一轮集中披露研究即可结束上市公司一般性研究，不得为凑轮次继续泛化检索。

### 非上市公司来源

非上市主体只按以下固定路径完成企业研究，不以媒体数量换取表面完整：

1. 企业官网、官方公众号、正式宣传材料，以及产品、服务、解决方案和项目页面；
2. 政府项目、备案、行政许可、政府采购和招投标记录；
3. 客户或合作方正式公告；
4. 工商登记与可公开取得的股权资料；
5. 行政处罚、经营异常、税务、裁判执行和信用名单等官方风险记录。

与企业所在地或项目相关的官方媒体、全国性主流媒体和财经媒体不属于主要业务、财务、行业地位、政府支持或风险的默认证明来源；只有固定路径结束后仍存在会改变招商结论的单一事实缺口时，才允许在一次定向补查中作为线索或补充，且不得替代原始材料。

不得采用：

- 小道消息；
- 自媒体和营销号；
- 无原始出处的转载；
- 明显的商业软文；
- 论坛、短视频口播和匿名爆料；
- 低质量商业信息汇总网站。

商业企业信息平台不得作为核心财务、业务及风险结论的唯一依据，也不是非上市路由的必查入口。只有用户提供可验证导出材料，或当前Agent确有合法可访问页面时，才可将企查查或天眼查用于主体、工商股东、页面显示持股比例、历史股东与穿透路径的补充复核，并按 `references/equity-evidence.md` 记录页面 URL、定位、时点和来源；不得绕过登录、验证码、付费墙或访问控制。涉及上市母公司时仍以法定披露定案，平台推算结论必须标为推定、疑似或平台穿透。

### 非上市公司经营与财务边界

- 收入、利润或纳税有可靠数据时填写对应年度；只取得部分年度或部分指标时，仅填写已核验部分，其余写“未公开披露”。
- 三项均无法可靠取得时，仍保留最近三个完整年度表，并写“本轮公开检索未发现可靠数据，需企业补充”。
- 政府项目、备案、许可、采购、招投标、公开融资和实际运营项目，只能支持经营真实性或项目执行能力，不能推算收入、利润、纳税，也不能替代财务数据。
- 不得根据注册资本、融资金额、产值、估值、项目金额或行业均值估算财务数据；后台 `financial_boundary.proxy_inference_used` 必须为 `false`。

### 非上市公司行业地位

先完成 `top500_status` 对 Fortune Global 500、中国企业500强和中国民营企业500强的固定核验；此外只检索与企业主营业务直接相关的一项行业500强。不得继续扩展市场份额、普通行业榜单、“头部”“第一梯队”、专精特新、单项冠军或其他荣誉。

行业500强命中时必须记录榜单全称、年度、名次、入选主体、发布机构和来源。入选主体为母集团时，必须说明集团与分析主体的关系，不得把集团名次直接归属于子公司。未命中时写“本轮未发现可核验的行业500强入选记录”并停止。

### 非上市公司政府支持

只有以下证据可以写成已经获得政府补助或政策支持：

1. 政府部门发布的补助、奖励或专项资金公示；
2. 政府项目立项、入选、验收或资金拨付文件；
3. 企业正式披露且明确具体政府部门和具体项目的材料。

申报、候选名单、意向协议或合作备忘录不得写成已获得支持；金额未公开时不得估算。未发现时写“本轮公开检索未发现可确认的政府补助或政策支持记录”。

### 非上市公司风险与合规

只核验四类对招商判断有实质影响的官方记录：行政处罚及经营异常、税务违法、重大诉讼及执行、失信及信用名单。普通小额纠纷不展开。每类发现事项时写明时间、事项、处理结果或当前状态及招商影响；未发现时写“本轮官方公开检索未发现相关记录”，不得写“无风险”；官方系统不可访问时写“本轮无法核验”，但不因单一系统不可用阻断整份报告。

非上市路由必查并在 `research_stop_gate.source_channels` 处置：`company_official`、`government_regulatory`、`business_registry`、`risk_records`。同时必须填写 `research_stop_gate.nonlisted_evidence_checks`，逐项处置企业自述、政府经营记录、客户/合作方公告、财务推算边界、行业500强、政府支持和四类官方风险。完成固定来源阶梯及一次定向补查后，仍无可靠财务、员工、行业500强或股权数据时，以明确的 `not_available` 或 `not_listed` 结论结束，不再转向无关网站反复搜索；股权没有可靠公开关系时按“无图继续交付”处理。

## 业务能力发现来源

年报用于财务和法定业务口径，但不得把其中未披露的业务能力反向当作不存在。上市路由只补查企业官网当前产品/服务/解决方案、最近一年重大变化和投资者关系战略材料；非上市路由先读取企业官网、官方公众号或正式材料中的产品、服务、解决方案和项目页面，再只用政府项目/备案/许可、政府采购/招投标及客户或合作方正式公告进行外部事实验证。只有企业自述时必须标为“据企业官方披露”；未获外部证据支持时不得升级为核心客户、重大项目或行业地位。海外业务必须有境外主体、项目、渠道、销售地区、出口或投资事实，只有英文网站不能认定海外业务。来源不可访问时记录原因和替代来源，不得静默跳过。
